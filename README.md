# Portfolio

Mi web de portfolio personal: quién soy, las tecnologías que uso, mis proyectos y cómo contactarme.

**Web:** https://jaaviidiaz.github.io/portfolio/

## Tecnologías

- **HTML** — estructura de la página por secciones (`index.html`)
- **CSS** — diseño oscuro con variables, grid y flexbox, adaptado a móvil con media queries (`style.css`)
- **JavaScript** — menú desplegable en móvil, resaltado de la sección activa y año del pie (`script.js`)

Publicada con GitHub Pages.
